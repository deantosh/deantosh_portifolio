### 🔹 3. **AirBnB Clone (Python/C)**

A simplified clone of the AirBnB platform with file and DB storage.
- **Key Features:**
  - Command Line Interface (Console):
    - Create, read, update, delete object instances (e.g., users, places)
    - Supports persistence with JSON file storage
    - Interactive mode with shell-like environment

  - Web Static:
    - Responsive landing page using custom HTML/CSS
    - Mimics original AirBnB layout design

  - Flask Web Framework:
    - Jinja2 templating to dynamically load states, cities, and places
    - Routes mapped to HTML pages using Python and Flask

  - Database Storage:
    - Swappable storage engine: FileStorage or DBStorage
    - MySQL + SQLAlchemy ORM
    - Models include User, Place, State, City, Amenity, Review
    - Supports relationships (One-to-Many, Many-to-Many)

  - RESTful API:
    - Full CRUD API for all models
    - JSON request/response with status codes
    - Proper error handling and input validation

  - Web Dynamic (JavaScript):
    - Real-time filter of places by amenities, cities, and states
    - Fetch data using AJAX and display without reloading
    - Interactive UI built with Vanilla JavaScript

- **🛠 Technologies:** Python, Flask, SQLAlchemy, MySQL, HTML, CSS, JavaScript
- **🤖 Role:** Full-stack contributor (CLI, API, web frontend, backend logic, data modeling))  
- **📁 [View Project](https://github.com/deantosh/AirBnB_clone_v3)**

### 🔹 4. **Linux Shell (C)**

A simple Unix command interpreter (shell) written in C, mimicking the basic behavior of `/bin/sh`.

- **Key Features:**
  - Displays a prompt and waits for user input
  - Executes commands with arguments (e.g., `ls -l /tmp`)
  - Handles built-in commands: `exit`, `env`
  - Supports command path resolution using `PATH`
  - Supports comments (ignores lines starting with `#`)
  - Handles signals (e.g., `Ctrl+C` doesn't exit the shell)
  - Supports command chaining using `;`
  - Custom memory management and error handling
  - Works in both interactive and non-interactive modes

- **🛠 Technologies:** C, Linux system calls, memory management
- **💾 Role:** Systems developer (Process management, parsing logic, I/O handling)
- **📁 [View Project](https://github.com/deantosh/simple_shell)**

### 🔹 5. **Fyyur Booking App (Python)**
Fyyur is a musical venue and artist booking site that facilitates the discovery and booking of shows between local performing artists and venues.

- **Key Features:**

- **🛠 Technologies:** Python, Flask, PostgreSQL, SQLAlchemy, HTML/CSS, WTForms
- **💾 Role:** Backend developer (Database modeling, ORM setup, form integration)
- **📁 [View Project](https://github.com/deantosh/project_fyyur)**
