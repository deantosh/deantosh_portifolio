PROJECTS

LuDa Chat

LuDa Chat is a real time chat application designed to allow user to create rooms of specific discussions. It also allows users to join rooms of interest and share ideas with like minded individuals. It connects users based on the areas of interest be it medicine, engineering, programming e.t.c

SavePals

SavePals is a collaborative savings platform that allows friends to save money together by setting group goals, tracking progress, and managing contributions.

AirBnB Clone

AirBnB Console is a s a full-stack clone of the core functionality of the Airbnb platform. It also includes a command-line interface (console) for interacting with the system’s data. Users can create, update, retrieve, and delete records such as users, places, amenities, and reviews.

Simple Shell

Simple Shell is a command-line interpreter that allows users to execute commands and manage processes. It supports built-in commands, environment variables, and input/output redirection.

Fyyur

Fyyur is a musical venue and artist booking site that facilitates the discovery and bookings of shows between local performing artists and venues. This site lets you list new artists and venues, discover them, and list shows with artists as a venue owner.
